# Сайт Олимпиадного МХК (ЛНИП)

```
index.html            — весь сайт (вход, материалы, тесты, редактор, личный кабинет, темы)
images/               — картинки для галерей в материалах
music/                — аудио для плеера
.nojekyll             — GitHub Pages отдаёт файлы как есть
apps-script/Code.gs   — серверная часть для Google Apps Script (на GitHub не нужна)
```

## Роли (столбец C листа Users)
| Роль         | Может |
|--------------|-------|
| Пользователь | читать материалы, проходить тесты |
| Роль 2       | + добавлять вопросы с картинками, удалять свои |
| Root         | + удалять любые вопросы |

## Лист Tests
ID | Тест | Минут | Тип | Вопрос | Варианты | Ответ | Пояснение | Картинка | Автор | Добавлен

- Тип: `один`, `несколько` или `текст`.
- Варианты: каждый с новой строки в ячейке (Ctrl+Enter).
- Ответ: номер верного варианта (`2`), для «несколько» — `1, 3`, для «текст» — варианты через `;`.
- Строки можно добавлять и руками, ID тогда можно не заполнять.
